ระบบเฝ้าระวังและเตือนภัยมลพิษระยะไกล (D-POMS)

คู่มือการใช้งานสำหรับผู้ประกอบการ

ตัวอย่างคู่มือเมนู “หน้าหลัก”
จัดทำเพื่ออธิบายขั้นตอนการตรวจสอบข้อมูลโรงงานและข้อมูลตรวจวัดในหน้าหลักของระบบ

1.วัตถุประสงค์

คู่มือฉบับนี้จัดทำขึ้นเพื่อให้ผู้ประกอบการสามารถใช้งานเมนูหน้าหลักของระบบ D-POMS ได้อย่างถูกต้อง โดยครอบคลุมการดูตำแหน่งโรงงานบนแผนที่ การตรวจสอบรายชื่อโรงงาน การค้นหาข้อมูล การเปิดดูรายละเอียดจุดตรวจวัด และการตรวจสอบค่าสถิติข้อมูลตรวจวัดเบื้องต้น

2.หัวข้อการใช้งาน

  1. องค์ประกอบของหน้าหลัก
  2. การใช้งานรายการโรงงาน
  3. การค้นหาและการค้นหาขั้นสูง
  4. การดูข้อมูลตรวจวัดล่าสุด
  5. การดูรายละเอียดโรงงานและสถิติข้อมูล
  6. คำอธิบายสัญลักษณ์และสี

3.องค์ประกอบของหน้าหลัก

เมื่อเข้าสู่ระบบและเลือกเมนู “หน้าหลัก” ระบบจะแสดงองค์ประกอบสำคัญ ดังนี้

ส่วนแสดงผล รายละเอียดการใช้งาน
แผนที่ แสดงตำแหน่งโรงงานที่อยู่ในระบบ โดยสามารถใช้เพื่อดูภาพรวมตำแหน่งโรงงานและเลือกโรงงานที่ต้องการตรวจสอบได้
รายการโรงงาน แสดงรายชื่อโรงงาน เลขทะเบียน ที่ตั้ง ระบบตรวจวัด และข้อมูลตรวจวัดล่าสุดของโรงงานแต่ละแห่ง
ช่องค้นหา ใช้ค้นหารายชื่อโรงงานหรือข้อมูลที่เกี่ยวข้องตามสิทธิ์การใช้งานของผู้ใช้งาน
ค้นหาขั้นสูง ใช้กำหนดเงื่อนไขเพิ่มเติม เช่น ประเภทโรงงาน พื้นที่ประกอบกิจการ ภาค จังหวัด หรือระดับการเฝ้าระวัง
แถบระบบ CEMS/WPMS ใช้เลือกดูข้อมูลตามประเภทระบบตรวจวัดของโรงงาน

4.การใช้งานรายการโรงงาน

  1. ตรวจสอบรายชื่อโรงงานจากแถบรายการด้านซ้ายหรือส่วนรายการโรงงานของหน้าจอ
  2. กดที่ชื่อโรงงานหรือโลโก้โรงงาน เพื่อให้แผนที่เลื่อนไปยังตำแหน่งของโรงงานที่เลือก
  3. กดปุ่มลูกศรหรือส่วนเปิดรายละเอียด เพื่อดูข้อมูลเพิ่มเติมของโรงงาน
  4. หากต้องการติดตามโรงงานเป็นพิเศษ ให้กดสัญลักษณ์รูปดาวของโรงงานนั้น
โรงงานที่ถูกกำหนดเป็นรายการโปรดจะแสดงในลำดับต้นของรายการ เพื่อให้ผู้ประกอบการตรวจสอบข้อมูลได้สะดวกยิ่งขึ้น

5.การค้นหาและการค้นหาขั้นสูง

5.1 การค้นหาจากชื่อโรงงาน

  1. กรอกชื่อโรงงานหรือข้อความที่ต้องการค้นหาในช่องค้นหา
  2. ระบบจะแสดงรายการโรงงานที่สอดคล้องกับคำค้นหาตามเงื่อนไขที่กำหนด
  3. เลือกโรงงานจากรายการเพื่อดูตำแหน่งบนแผนที่หรือเปิดดูรายละเอียด

5.2 การค้นหาขั้นสูง

  1. กดปุ่ม “ค้นหาขั้นสูง”
  2. เลือกเงื่อนไขที่ต้องการ เช่น ลำดับประเภทโรงงาน นิคมอุตสาหกรรม ภาค จังหวัด เขต/อำเภอ หรือการเฝ้าระวัง
  3. กดปุ่ม “ค้นหา” เพื่อให้ระบบแสดงโรงงานที่ตรงกับเงื่อนไข
  4. หากต้องการยกเลิกเงื่อนไขทั้งหมด ให้กดปุ่ม “ค่าเริ่มต้น”
กรณีเลือกตัวเลือก “ทั้งหมด” ระบบจะไม่นำเงื่อนไขในช่องนั้นไปจำกัดผลการค้นหา

6.การดูข้อมูลตรวจวัดล่าสุด

ในการ์ดรายชื่อโรงงาน ระบบจะแสดง Chip ของระบบตรวจวัด เช่น CEMS หรือ WPMS เมื่อกด Chip ดังกล่าว ระบบจะแสดงตารางค่าตรวจวัดล่าสุดของจุดตรวจวัดภายในโรงงานนั้น

ข้อมูลในตาราง คำอธิบาย
จุดตรวจวัด แสดงชื่อจุดตรวจวัดของโรงงาน
วันที่และเวลา แสดงวันและเวลาของข้อมูลตรวจวัดล่าสุดที่ระบบได้รับ
ค่าพารามิเตอร์ แสดงค่าตรวจวัดของแต่ละพารามิเตอร์ พร้อมสีเพื่อบ่งชี้สถานะของข้อมูล

7.การดูรายละเอียดโรงงานและสถิติข้อมูล

  1. กดปุ่มเปิดรายละเอียดของโรงงานจากรายการโรงงาน
  2. ระบบจะแสดงหน้าต่างรายละเอียดด้านล่างของหน้าจอ
  3. เลือกประเภทระบบ เช่น CEMS หรือ WPMS ตามข้อมูลที่ต้องการตรวจสอบ
  4. เลือกวันที่ที่ต้องการดูข้อมูลจากช่องวันที่
  5. ตรวจสอบตารางสถิติข้อมูล กราฟแนวโน้มสถานการณ์มลพิษ และตารางสรุปผลการตรวจวัด
  6. หากต้องการส่งออกข้อมูล ให้กดปุ่ม “Export” แล้วเลือกเงื่อนไขการส่งออกตามที่ระบบกำหนด
ตารางสถิติข้อมูลรายชั่วโมงใช้สำหรับตรวจสอบค่าตรวจวัดในแต่ละช่วงเวลา ส่วนกราฟแนวโน้มใช้สำหรับพิจารณาภาพรวมการเปลี่ยนแปลงของค่ามลพิษตามวันที่เลือก

8.คำอธิบายสัญลักษณ์และสี

สีเขียว
ค่าตรวจวัดอยู่ในระดับปกติ หรือการส่งข้อมูลครบถ้วนตามเกณฑ์
สีส้ม
ค่าตรวจวัดอยู่ในระดับเฝ้าระวัง หรือมีข้อมูลบางส่วนที่ควรตรวจสอบเพิ่มเติม
สีแดง
ค่าตรวจวัดเกินมาตรฐาน หรือข้อมูลมีลักษณะที่ระบบจัดเป็นความผิดปกติ
สีเทา
ไม่มีข้อมูลล่าสุด ข้อมูลไม่เพียงพอ หรือเป็นสถานะการทำงานของอุปกรณ์
สัญลักษณ์ ความหมาย
* ไม่มีการติดตั้งพารามิเตอร์ดังกล่าว
- มีการติดตั้ง แต่ไม่ส่งข้อมูลในช่วงเวลานั้น
ERR ค่าตรวจวัดติดลบ หรือข้อมูลมีรูปแบบผิดปกติ

9.ข้อควรปฏิบัติ

  • ควรตรวจสอบข้อมูลโรงงานและตำแหน่งบนแผนที่ให้ถูกต้องก่อนนำข้อมูลไปใช้อ้างอิง
  • หากพบข้อมูลตรวจวัดเป็นสีแดงหรือสีส้มต่อเนื่อง ควรตรวจสอบสถานะอุปกรณ์และการส่งข้อมูลของโรงงาน
  • หากข้อมูลไม่แสดงหรือไม่เป็นปัจจุบัน ควรตรวจสอบการเชื่อมต่ออินเทอร์เน็ตและลองโหลดข้อมูลใหม่อีกครั้ง
  • กรณีพบข้อมูลคลาดเคลื่อน ควรติดต่อเจ้าหน้าที่ผู้ดูแลระบบเพื่อดำเนินการตรวจสอบ
เอกสารฉบับนี้เป็นตัวอย่างคู่มือสำหรับเมนูหน้าหลัก และอาจปรับปรุงเพิ่มเติมให้สอดคล้องกับหน้าจอระบบจริงในแต่ละช่วงเวลา
