# ส่งต่อความต้องการหน้า ข้อมูลทั่วไป

เอกสารนี้อธิบายงาน Frontend และข้อเสนอสำหรับ API ใหม่ ไม่ใช่สัญญา API ที่ Backend เผยแพร่แล้ว เมื่อ Backend รองรับ ให้เผยแพร่สัญญาจริงที่ [ศูนย์เอกสาร Backend](../../docs/backend/README.md) และปรับตัวเชื่อมต่อ Frontend หากชื่อฟิลด์แตกต่างกัน

## จุดประสงค์และสิทธิ์

- เพิ่มเมนู **ข้อมูลทั่วไป** ต่อจาก **การสืบค้นข้อมูลแบบมีเงื่อนไข**
- เห็นและเข้าได้เฉพาะเจ้าหน้าที่ทุกระดับและแอดมิน ผู้ประกอบการและประชาชนเข้าไม่ได้
- เจ้าหน้าที่และแอดมินเห็นข้อมูลทั่วประเทศชุดเดียวกัน ไม่จำกัดภาคหรือจังหวัดตามพื้นที่รับผิดชอบ
- แยกแท็บ CEMS และ WPMS ไม่มีการโหลดซ้ำตามเวลา โหลดเมื่อเข้าหน้า เปลี่ยนแท็บ หรือกดรีเฟรช
- ส่งออก Excel `.xlsx` และ PDF เฉพาะระบบที่เลือก โดยใช้ snapshot เดียวกับหน้าจอ ไม่มี API ส่งออกแยก

## ขอบเขตการนับที่ยืนยันแล้ว

1. ใช้ข้อมูลจุดตรวจวัดที่เคยเชื่อมต่อในระบบ POMS รวมจุดที่ซ่อนหรือยกเลิกการเชื่อมต่อแล้วตามที่ผู้ใช้ยืนยัน ไม่รวมโรงงานที่เข้าข่ายซึ่งไม่เคยเชื่อมต่อ และไม่นับคำขอที่ยังไม่สำเร็จเป็นจุดติดตั้ง
2. นับโรงงานไม่ซ้ำตามตัวตนโรงงาน และจุดตรวจวัดไม่ซ้ำตามตัวตนจุด ไม่ใช้จำนวนแถวประวัติหรือ revision หากจุดเดียวมีหลายบันทึกให้ใช้ข้อมูลล่าสุดของจุดนั้น
3. โรงงานเดียวมีทั้ง CEMS และ WPMS นับในแต่ละระบบได้ แต่ไม่นับโรงงานซ้ำภายในระบบเดียวกัน
4. แบ่งตามภาคกรมโรงงาน: เหนือ กลาง ตะวันออกเฉียงเหนือ ตะวันตก ตะวันออก ใต้ โดยชัยนาทและอุทัยธานีอยู่ภาคกลาง เหนือมี 16 จังหวัด
5. ภาคที่ไม่มีข้อมูลส่งจำนวน 0 ไม่ละภาคนั้น ยอดทั่วประเทศเป็นจำนวนโรงงานและจุดไม่ซ้ำ ไม่บวกยอดโรงงานรายพารามิเตอร์
6. นิคมแบ่งเพียง **ในนิคมฯ / นอกนิคมฯ** ไม่เพิ่มหมวดเขตประกอบการตามภาพตัวอย่าง ใช้ข้อมูลนิคมที่มีความหมายจริง ไม่ถือข้อความว่างหรือเครื่องหมาย `-` เป็นชื่อนิคม
7. รายพารามิเตอร์รวมหน่วยต่างกันภายใต้พารามิเตอร์เดียวกัน เช่น CO (ppm) กับ CO (%) รวม CO แต่ CO กับ CO2 ต้องแยกกัน จุดที่มีทั้งสองหน่วยนับเพียงหนึ่งครั้งสำหรับพารามิเตอร์นั้น โรงงานที่มีหลายจุดนับโรงงานเพียงหนึ่งครั้งต่อพารามิเตอร์

## อัตราการระบาย

- ใช้ค่าที่บันทึกในข้อมูลจุดตรวจวัด ไม่ใช้ค่าทดสอบอุปกรณ์หรือค่าตรวจวัดออนไลน์
- เฉลี่ย = ค่าเฉลี่ยของค่าเฉลี่ยที่มีข้อมูลในแต่ละจุด
- ต่ำสุด = ค่าต่ำสุดของช่องต่ำสุดที่มีข้อมูล
- สูงสุด = ค่าสูงสุดของช่องสูงสุดที่มีข้อมูล
- ขาดค่าใด ให้ไม่นำจุดนั้นเข้าสูตรของค่านั้น โดย 0 เป็นข้อมูลจริง ไม่ถือว่าขาด
- ไม่มีค่าที่ใช้คำนวณ ส่ง `null` และ Frontend แสดง `-`
- ค่าทั่วประเทศคำนวณจากจุดทั้งหมด ไม่ใช่ค่าเฉลี่ยของค่าเฉลี่ย 6 ภาค
- หน่วยผลลัพธ์ CEMS `m³/hr`, WPMS `m³/d`; Backend ต้องปรับหน่วยข้อมูลต้นทางให้ตรงก่อนรวม ห้ามรวมต่างหน่วยโดยตรง
- ไม่ใช้ตัวเลขในภาพตัวอย่างเป็นค่าจริงของระบบ

## สิ่งที่ Backend ต้องเพิ่ม

- API สรุปข้อมูล 4 หัวข้อ โดยบังคับสิทธิ์เจ้าหน้าที่/แอดมินที่ Backend ด้วย ไม่อาศัยการซ่อนเมนู
- ส่งยอดสรุปทั่วประเทศทั้งชุดในคำตอบเดียวของระบบที่เลือก ไม่แบ่งหน้าข้อมูลสรุป และไม่ส่งข้อมูลส่วนบุคคล
- ให้ข้อมูลทั้ง 4 หัวข้ออยู่บนขอบเขตเดียวกัน พร้อมเวลาที่จัดทำข้อมูล
- เผยแพร่ endpoint/schema/สิทธิ์/error ใน canonical docs และ runtime OpenAPI ก่อนใช้งานจริง
- ข้อมูลภาค/นิคมที่จัดหมวดไม่ได้ต้องตรวจสอบ ไม่ทิ้งเงียบ ๆ จนยอดรวมไม่ตรง หากพบกรณีดังกล่าวให้ตกลงหมวดเพิ่มเติมก่อนเปลี่ยนสัญญา

## ตัวเชื่อมต่อ Frontend ที่เตรียมไว้ (ข้อเสนอ ยังไม่ยืนยันจาก Backend)

Frontend เตรียมเรียก `GET /api/v1/general-information?systemType=CEMS` หรือ `WPMS` พร้อม Bearer token ไม่มี request body ไม่มีการเขียนข้อมูล

ตัวเชื่อมต่ออยู่ใน `src/utils/generalInformation.mjs` หาก Backend ใช้ endpoint/schema อื่นให้แก้ไฟล์นี้ตาม canonical contract ที่ได้รับการยืนยัน

โครงสร้างที่ Frontend เตรียมรับ:

| ฟิลด์ใน `data` | รูปแบบ |
| --- | --- |
| `systemType` | `CEMS` หรือ `WPMS` ตรงกับระบบที่ร้องขอ |
| `generatedAt` | ISO datetime มี timezone |
| `regions` | 6 แถว `{ label, factoryCount, pointCount }` ชื่อภาคเต็มตามลำดับข้างต้น |
| `total` | `{ label: "ทั่วประเทศ", factoryCount, pointCount }` |
| `estates` | 2 แถว `{ label: "ในนิคมฯ" หรือ "นอกนิคมฯ", factoryCount, pointCount }` |
| `parameters` | แถว `{ label, factoryCount, pointCount }` หลังรวมพารามิเตอร์ต่างหน่วยแล้ว ไม่มีหน่วยใน label ของรายงานสรุปนี้ |
| `flowRates` | 6 แถว `{ label, average, min, max }` ตามภาค |
| `flowTotal` | `{ label: "ทั่วประเทศ", average, min, max }` |

Envelope ที่เตรียมรับคือ `{ "success": true, "data": { ... } }` จำนวนเป็น JSON number จำนวนเต็มไม่ติดลบ; อัตราการระบายเป็น JSON number หรือ null ไม่รับสตริงตัวเลข

Frontend ไม่รวมพารามิเตอร์หรือคำนวณยอดจากรายการโรงงานเอง เพราะยอดโรงงานแบบ distinct ไม่สามารถบวกจากยอดย่อยได้อย่างถูกต้อง

## สถานะการส่งมอบ

- ทำหน้า UI, ตรวจสิทธิ์เมนูและหน้าจอ, ตัวเชื่อมต่อ, Excel/PDF แล้ว
- เมื่อ API ตอบ 404/501 จะแสดงยังไม่มีข้อมูลสรุปและปิดปุ่มส่งออก ไม่ใช้ข้อมูลจำลองหรือแสดงศูนย์แทนข้อผิดพลาด
- API ล้มเหลวหรือส่งข้อมูลไม่ครบแสดง error ให้รีเฟรชเอง; ไม่แสดงข้อมูลเก่าของอีกแท็บ
- ยังต้องตรวจ end-to-end กับ API จริงหลัง Backend เพิ่มการรองรับ
- ไม่แก้ payload/endpoint ของเมนูเดิม และไม่แก้ Backend ในงานนี้
