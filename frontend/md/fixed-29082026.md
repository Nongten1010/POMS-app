# fixed-29082026

## ขอบเขต

เอกสารนี้สรุปรูปแบบข้อมูลของหน้า `สิทธิ์การใช้งาน` หลังปรับ frontend ล่าสุด เพื่อให้ backend ปรับ request/response ให้ตรงกับ UI

## สิ่งที่ frontend ปรับ

- เอาช่อง `ข้อมูล` ออกจาก section ต่อไปนี้
  - `จัดการสิทธิ์การใช้งาน` (`permissions`)
  - `แจ้งขอความช่วยเหลือ` (`helpdesk`)
  - `ข้อเสนอแนะ` (`feedback`)
  - `กฎหมายที่เกี่ยวข้อง` (`laws`)
  - `คำถามที่พบบ่อย` (`faq`)
  - `Chat` (`chat`)
- section ข้างต้น frontend ไม่ส่ง `data`, `region`, `province` ใน payload แล้ว
- ตัด action ต่อไปนี้ออกจาก UI และ payload
  - `connection.direct_connect`
  - `notifications.view_status`
  - `notifications.edit`
  - `notifications.approve`
  - `permissions.manage`
  - `api_documentation.*`
