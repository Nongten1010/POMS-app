# fixed-04092026

## ขอบเขต

เอกสารนี้ระบุเฉพาะข้อมูลและการทำงานที่ frontend ของเมนู `กฎหมายที่เกี่ยวข้อง` และ `คำถามที่พบบ่อย` ต้องใช้จาก backend โดยไม่กำหนดวิธี implementation, path, method, database, storage หรือวิธีตรวจสอบสิทธิ์ของ backend

ปัจจุบัน frontend ทั้งสองเมนูยังใช้ข้อมูล mock ภายใน `src/pages/LawsPage.jsx` และ `src/pages/FaqPage.jsx`

## เมนูกฎหมายที่เกี่ยวข้อง

### ฟังก์ชันที่ frontend ต้องใช้

Frontend ต้องสามารถดำเนินการต่อไปนี้ได้

- โหลดรายการกฎหมายทั้งหมด
- เพิ่มรายการกฎหมายพร้อมไฟล์แนบ
- แก้ไขข้อมูลรายการกฎหมาย
- เปลี่ยนไฟล์แนบของรายการกฎหมาย
- ลบรายการกฎหมาย
- ดาวน์โหลดไฟล์แนบจากปุ่ม `ดาวน์โหลดไฟล์`

### ตัวเลือกใน frontend

#### หมวดหมู่

| ค่าที่ frontend ใช้ | ข้อความที่แสดง |
| --- | --- |
| `CEMS` | `CEMS` |
| `WPMS` | `WPMS` |
| `OTHER` | `อื่นๆ` |

#### ประเภท

| ค่าที่ frontend ใช้ | ข้อความที่แสดง |
| --- | --- |
| `MINISTERIAL_REGULATION` | `กฎกระทรวง` |
| `RULE_AND_ANNOUNCEMENT` | `กฎและประกาศ` |
| `REGULATION_REQUIREMENT` | `ระเบียบ ข้อบังคับ และข้อกำหนด` |
| `OTHER` | `อื่นๆ` |

### 1. โหลดรายการกฎหมายทั้งหมด

Frontend ต้องได้รับรายการทั้งหมดในการโหลดครั้งเดียว โดยไม่ใช้ `page`, `perPage`, query สำหรับกรอง หรือ query สำหรับเรียงลำดับ

ข้อมูลแต่ละรายการที่ frontend ต้องใช้:

| ฟิลด์ | ชนิด | การใช้งานใน frontend |
| --- | --- | --- |
| `id` | string | ระบุรายการสำหรับแก้ไขและลบ |
| `title` | string | แสดงชื่อรายการ |
| `category` | enum | กรองเมนูย่อย |
| `categoryLabel` | string | แสดงชื่อหมวดหมู่ |
| `type` | enum | ระบุประเภทเอกสาร |
| `typeLabel` | string | แสดงชื่อประเภท |
| `publishedDate` | string (`YYYY-MM-DD`) | แสดงวันที่และใส่ค่าเริ่มต้นใน datepicker |
| `file.fileName` | string | แสดงชื่อไฟล์ |
| `file.fileSize` | integer | ขนาดไฟล์หน่วย byte |
| `file.mimeType` | string | ประเภทไฟล์ |
| `file.downloadUrl` | string | ใช้กับปุ่มดาวน์โหลดโดยตรง |
| `createdAt` | ISO 8601 datetime | ข้อมูลวันที่สร้าง |
| `updatedAt` | ISO 8601 datetime | ข้อมูลวันที่แก้ไขล่าสุด |

ตัวอย่างข้อมูลที่ frontend ต้องได้รับ:

```json
{
  "success": true,
  "data": [
    {
      "id": "law_001",
      "title": "ประกาศกรมโรงงานอุตสาหกรรม เรื่อง การทวนสอบและสอบเทียบระบบ CEMS",
      "category": "CEMS",
      "categoryLabel": "CEMS",
      "type": "RULE_AND_ANNOUNCEMENT",
      "typeLabel": "กฎและประกาศ",
      "publishedDate": "2025-07-09",
      "file": {
        "fileName": "cems-calibration-announcement.pdf",
        "fileSize": 824512,
        "mimeType": "application/pdf",
        "downloadUrl": "https://example.com/download/cems-calibration-announcement.pdf"
      },
      "createdAt": "2026-09-04T09:30:00.000Z",
      "updatedAt": "2026-09-04T09:30:00.000Z"
    }
  ]
}
```

Frontend จะเก็บ `data` ไว้และกรองด้วย dropdown หมวดหมู่เองดังนี้

| ตัวเลือก | การกรองใน frontend |
| --- | --- |
| `ทั้งหมด` | แสดงทุกรายการ |
| `CEMS` | `category === "CEMS"` |
| `WPMS` | `category === "WPMS"` |
| `อื่นๆ` | `category === "OTHER"` |

Frontend เป็นผู้เรียงรายการตาม `title` และไม่ต้องการข้อมูล pagination

### 2. เพิ่มรายการกฎหมาย

ข้อมูลที่ frontend ส่ง:

| ฟิลด์ | ชนิด | บังคับ |
| --- | --- | --- |
| `title` | string | ใช่ |
| `category` | enum | ใช่ |
| `type` | enum | ใช่ |
| `publishedDate` | string (`YYYY-MM-DD`) | ใช่ |
| `file` | binary file | ใช่ |

วันที่ใน UI แสดงเป็นปี พ.ศ. แต่ frontend ส่ง `publishedDate` เป็นรูปแบบ `YYYY-MM-DD`

ตัวอย่างข้อมูล:

```json
{
  "title": "ประกาศกรมโรงงานอุตสาหกรรม เรื่อง การทวนสอบและสอบเทียบระบบ CEMS",
  "category": "CEMS",
  "type": "RULE_AND_ANNOUNCEMENT",
  "publishedDate": "2025-07-09",
  "file": "<binary-file>"
}
```

เมื่อเพิ่มสำเร็จ frontend ต้องได้รับข้อมูลรายการที่สร้างแล้วในรูปแบบเดียวกับรายการจากการโหลดทั้งหมด เพื่อใช้ `id` และ `file.downloadUrl` ต่อได้ทันที

```json
{
  "success": true,
  "data": {
    "id": "law_001",
    "title": "ประกาศกรมโรงงานอุตสาหกรรม เรื่อง การทวนสอบและสอบเทียบระบบ CEMS",
    "category": "CEMS",
    "categoryLabel": "CEMS",
    "type": "RULE_AND_ANNOUNCEMENT",
    "typeLabel": "กฎและประกาศ",
    "publishedDate": "2025-07-09",
    "file": {
      "fileName": "cems-calibration-announcement.pdf",
      "fileSize": 824512,
      "mimeType": "application/pdf",
      "downloadUrl": "https://example.com/download/cems-calibration-announcement.pdf"
    },
    "createdAt": "2026-09-04T09:30:00.000Z",
    "updatedAt": "2026-09-04T09:30:00.000Z"
  }
}
```

### 3. แก้ไขรายการกฎหมาย

Frontend ใช้ `id` ระบุรายการที่ต้องแก้ไข และส่งข้อมูลดังนี้

| ฟิลด์ | ชนิด | รายละเอียด |
| --- | --- | --- |
| `title` | string | ชื่อรายการล่าสุด |
| `category` | enum | หมวดหมู่ล่าสุด |
| `type` | enum | ประเภทล่าสุด |
| `publishedDate` | string (`YYYY-MM-DD`) | วันที่ล่าสุด |
| `file` | binary file | ส่งเมื่อผู้ใช้เลือกไฟล์ใหม่ |

ตัวอย่างข้อมูล:

```json
{
  "id": "law_001",
  "title": "ประกาศฉบับแก้ไข เรื่อง การทวนสอบระบบ CEMS",
  "category": "CEMS",
  "type": "RULE_AND_ANNOUNCEMENT",
  "publishedDate": "2026-09-04",
  "file": "<new-binary-file-or-not-sent>"
}
```

ถ้าผู้ใช้ไม่ได้เลือกไฟล์ใหม่ frontend จะไม่ส่ง `file` และยังแสดงไฟล์เดิม เมื่อแก้ไขสำเร็จ frontend ต้องได้รับข้อมูลรายการล่าสุดในรูปแบบเดียวกับรายการจากการโหลดทั้งหมด

### 4. ลบรายการกฎหมาย

Frontend ส่ง `id` ของรายการที่ผู้ใช้ยืนยันลบ

```json
{
  "id": "law_001"
}
```

ข้อมูลตอบกลับที่ frontend ต้องใช้:

```json
{
  "success": true,
  "data": {
    "id": "law_001",
    "deleted": true
  }
}
```

เมื่อสำเร็จ frontend จะเอารายการนั้นออกจากรายการที่แสดง

### 5. ดาวน์โหลดไฟล์

Frontend ใช้ `file.downloadUrl` ที่ได้รับจากข้อมูลรายการกับปุ่ม `ดาวน์โหลดไฟล์` โดยตรง

วิธีสร้าง URL, รูปแบบ URL และวิธีส่งไฟล์ให้ frontend เป็นส่วนที่ backend กำหนดเอง Frontend ต้องการเพียง URL ที่ใช้งานได้สำหรับรายการนั้น

### ข้อมูล error ที่ frontend ต้องใช้

เมื่อดำเนินการไม่สำเร็จ frontend ต้องอ่านข้อความสำหรับแสดงให้ผู้ใช้ได้จาก `error.message` และสามารถอ่านรายละเอียดรายฟิลด์จาก `error.details`

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "ข้อมูลรายการกฎหมายไม่ถูกต้อง",
    "details": {
      "category": "กรุณาเลือกหมวดหมู่",
      "file": "ไฟล์ไม่ถูกต้อง"
    }
  }
}
```

### สรุปสิ่งที่ frontend ต้องได้รับ

- ข้อมูลรายการทั้งหมดในครั้งเดียว
- ค่า `id` ที่คงที่สำหรับแก้ไขและลบ
- ค่า `category` และ `type` ตรงตาม enum ในเอกสารนี้
- ค่า label ภาษาไทยสำหรับแสดงผล
- วันที่รูปแบบ `YYYY-MM-DD`
- ข้อมูลไฟล์และ `file.downloadUrl`
- ข้อมูลรายการล่าสุดหลังเพิ่มหรือแก้ไขสำเร็จ
- ผลลัพธ์ยืนยันหลังลบสำเร็จ
- `error.message` และ `error.details` เมื่อเกิดข้อผิดพลาด
