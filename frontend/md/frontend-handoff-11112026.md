# หน้าหลัก: ข้อมูลรายนาทีของชั่วโมงที่เลือก

## จุดประสงค์

ให้ผู้ใช้ดูข้อมูลรายนาทีที่จัดเก็บไว้ เพื่อเทียบตรวจสอบค่ารายชั่วโมงด้วยตนเอง ฟังก์ชันนี้ใช้งานเป็นครั้งคราว ไม่เพิ่มการคำนวณใหม่ทั้ง Frontend และ Backend

## การเปลี่ยนแปลง Frontend

- กดช่วงเวลาในตารางสถิติรายชั่วโมงของหน้าหลักเพื่อเปิด dialog เฉพาะชั่วโมงนั้น
- หัว dialog ระบุรหัสและชื่อจุดตรวจวัด วันที่ และช่วงชั่วโมงที่เลือก
- ตารางแสดงเวลาแต่ละนาทีครบ 60 แถว โดยเรียงจากนาที 00 ถึง 59
- ทุกพารามิเตอร์มีค่าตรวจวัดและสถานะแยกคอลัมน์อยู่ติดกัน พร้อมหน่วยในชื่อพารามิเตอร์
- ทุกคอลัมน์กว้างเท่ากัน รวมคอลัมน์เวลา เลื่อนแนวนอนได้และตรึงคอลัมน์เวลา
- ไม่มีข้อมูลให้แสดงขีด ไม่ใช้ศูนย์แทนข้อมูลที่ขาด และไม่ปัดเศษค่าตรวจวัดเพิ่มเติม
- มีสถานะกำลังโหลด ไม่พบข้อมูล โหลดไม่สำเร็จ และปุ่มปิด
- ปิด dialog แล้วกลับมาที่ตารางรายชั่วโมงเดิม ไม่เปลี่ยนวันที่ จุดตรวจวัด หรือพารามิเตอร์
- ไม่เพิ่มกราฟ Export ตัวกรอง การเปลี่ยนชั่วโมงใน dialog หรือการรีเฟรชอัตโนมัติ

## ข้อมูลที่ต้องใช้จาก Backend

- ข้อมูลรายนาทีจากตารางที่มีอยู่เดิม เฉพาะจุดตรวจวัด วันที่ และชั่วโมงที่ผู้ใช้เปิดดู ไม่ต้องคำนวณค่าใหม่
- ต้องทราบเวลาของแต่ละแถว โดยอ้างอิงชั่วโมงเดียวกับตารางรายชั่วโมงที่ผู้ใช้กด และใช้เขตเวลาไทยให้ตรงกัน
- ส่งค่าตรวจวัดกับสถานะคู่กันเสมอ แยกเป็นข้อมูลคนละส่วน ห้ามแปลงหรือแทนค่าตรวจวัดด้วยสถานะ
- แม้สถานะไม่ใช่ Normal ต้องยังส่งค่าตรวจวัดที่จัดเก็บไว้มาให้ด้วย
- หากไม่มีค่าตรวจวัดให้เป็นข้อมูลว่าง ไม่แทนด้วยศูนย์ และคงสถานะที่มีอยู่
- ข้อมูลต้องระบุพารามิเตอร์พร้อมหน่วย เพื่อแยกพารามิเตอร์ชื่อเดียวกันแต่คนละหน่วย
- ใช้ขอบเขตสิทธิ์เดียวกับการดูข้อมูลรายชั่วโมงของจุดตรวจวัดนั้น
- เรียกข้อมูลเฉพาะเมื่อเปิด dialog ไม่โหลดข้อมูลรายนาทีล่วงหน้าทั้งวัน

## สถานะการเชื่อมต่อ

Frontend ทำปุ่มเปิดและ dialog พร้อมรองรับตารางและสถานะการโหลดแล้ว แต่ยังไม่เชื่อม API จริง เนื่องจากเอกสารปัจจุบันยังไม่มีสัญญาสำหรับอ่านรายนาทีเฉพาะชั่วโมง หน้าจอจึงแสดงว่าข้อมูลรายนาทียังไม่พร้อมใช้งาน และไม่สร้างข้อมูลจำลองหรือเรียก endpoint ที่คาดเดาเอง

เอกสารนี้ระบุพฤติกรรมและความต้องการข้อมูลเท่านั้น ไม่กำหนดชื่อ endpoint โครงสร้าง request/response หรือวิธีดำเนินการของ Backend เมื่อมีสัญญา API จึงเชื่อมตัวโหลดข้อมูลเข้ากับ dialog อีกครั้ง
