# TDD Evidence: จุดตรวจวัดที่ได้รับการยกเว้นทั้งหมดเป็น Active POMS Point

## Source

ไม่มีไฟล์แผนแยก; acceptance criteria มาจากข้อกำหนดให้ผู้ประกอบการยื่นคำขอเพิ่มจุดตรวจวัดแบบ 1 คำขอต่อ 1 จุด โดยส่ง `monitoringPointStatus = "ได้รับการยกเว้นทั้งหมด"` และไม่มีพารามิเตอร์ได้ เมื่อเจ้าหน้าที่อนุมัติคำขอต้องเป็น `CONNECTED` และจุดต้องเป็น current/live active POMS point ทันที

Canonical contracts:

- [`connection-requests`](../../api/menus/connection-requests/README.md)
- [`request payloads and validation`](../../api/menus/connection-requests/request-payloads-and-validation.md)
- [`home dashboard`](../../api/menus/home/README.md)

## User journey

โรงงานที่อยู่ระหว่างก่อสร้างต้องลงทะเบียนจุดตามกฎหมาย แต่ยังไม่พร้อมติดตั้งอุปกรณ์ จึงยื่นคำขอเพิ่มจุดโดยเลือกสถานะได้รับการยกเว้นทั้งหมดและส่งรายการพารามิเตอร์ว่าง เจ้าหน้าที่อนุมัติแล้วระบบออกรหัสจุด สร้าง active point และปิดคำขอเป็น `CONNECTED`. โรงงานยังใช้จุดดังกล่าวยื่นแบบ กวภ.01-05 และทำคำขอ `ADD_PARAMETER` ด้วย `pointCode` เดิมเมื่อพร้อมติดตั้งในภายหลังได้
